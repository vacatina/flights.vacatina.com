# Coding Agent Handoff

Build the Vacatina holiday-package UI/UX using the seed data in this folder. Treat the TypeScript interfaces and normalized package objects as the frontend contract. Do not create a database, CMS, API, or admin workflow for this prototype.

Use `holidayPackages` for the listing page and `[slug]` detail routes. Render the complete itinerary, long-form content, route, inclusions/exclusions, season note, best-for tags, activity level, media gallery slots, and enquiry CTA. Build components so the static data layer can later be replaced by an API without changing the presentational UI.

The actual image binaries were not present in the supplied seed archive. Use the retained media paths as integration targets; during UI work, map missing assets to local placeholders without deleting the original filename metadata.
